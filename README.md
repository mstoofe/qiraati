# قراءتي — مغامرة القراءة

لعبة تعليمية تفاعلية لكتاب **قراءتي للصف الثاني الابتدائي** (المنهج العراقي، الطبعة السابعة عشرة ٢٠٢٥).

- **قطار الحروف** (مراجعة الحروف، ص ٥–١٢): الحرف الضائع، شكل الحرف، المقطع الضائع، اسمع واختر، أكمل بـ «الـ».
- **حقيبة المدرسة** (مدرستي، ص ١٧–٢٤): نشيد باسم الله، أنتَ/أنتِ/أنتما، أشياء صفّي، رتّب الفقرة، نشيد مدرستي.
- **الغراب العطشان** (ص ٢٥–٢٨): فهم القصة، مطر التنوين، الكلمات الضائعة، سلال الألف، ترتيب الحكاية.

الأصوات مولّدة بـ Google AI Studio. اللعبة تعمل دون إنترنت بعد أول فتح (تطبيق ويب PWA):
افتحها في Safari على الآيباد ← مشاركة ← «إضافة إلى الشاشة الرئيسية»، ثم افتحها من الأيقونة مرة واحدة وأنت متصل.

مجانية للأطفال والأهل والمعلمين، دون تسجيل ودون إعلانات، ولا تجمع أي بيانات عن الطفل.
